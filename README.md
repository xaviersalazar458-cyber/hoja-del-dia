# Hoja del Día

Planificador diario instalable en el móvil (PWA): 3 prioridades, agenda por horas, tareas por categoría y notas.

**Privacidad:** los datos se guardan solo en el almacenamiento local del dispositivo. La app no tiene servidor ni envía nada a ningún sitio. Desde «Tus datos» puedes guardar y restaurar una copia en un archivo `.json`.

Funciona sin conexión una vez abierta por primera vez.
